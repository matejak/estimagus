Estimagus documentation
=======================

Estimagus is a decision support tool for project management with focus on projects that follow the Agile methodology.
It aims to use statistical methods to help to plan by visualizing uncertainty, and therefore helping actors to find out what is the most meaningful course of action.
The project aims to use:

#. Estimation uncertainty (three-point estimations)

   - small size (tasks, stories)
   - large size (features)

#. Velocity uncertainty.

#. Uncertainty of assignment of individual tasks.

#. Uncertainty of priority.
